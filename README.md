## 💫 Về bản thân mình

<img align="right" width="340" src="https://media4.giphy.com/media/v1.Y2lkPTc5MGI3NjExZzk5bzllbXU1MzZ3cHJoZHBkNTEwazFsNzRiZTQyc2w4c3FwYzk1eSZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/1BjW0LNnhSyurA6Xw8/giphy.gif" alt="Cute cat typing" />

Xin chào! Mình là **Nguyễn Đình Sơn** (hay còn gọi là **Mountain** - *Sơn là Núi* 🏔️), một kỹ sư phần mềm đầy nhiệt huyết đến từ **Hà Nội, Việt Nam 🇻🇳**. Mình là sinh viên ngành Công nghệ Thông tin tại **PTIT**, sở hữu thế mạnh kết hợp giữa kiến trúc hệ thống **Backend**, quy trình tự động hóa **DevOps**, tích hợp ứng dụng **AI** thông minh và tối ưu hóa hiệu năng **SEO/Web**.

- 💻 **Backend Engineering:** Phát triển hệ thống vững chắc với **Java**, **Spring Boot**, kiến trúc **Microservices** và hệ sinh thái **Spring Cloud (Eureka, Gateway, Config Server)**.
- ⚙️ **DevOps & CI/CD:** Thực hành đóng gói ứng dụng với **Docker**, tự động hóa quy trình tích hợp và triển khai liên tục (**CI/CD Pipelines** với GitHub Actions / Jenkins), quản lý môi trường và Linux server.
- 🤖 **AI Application & Integration:** Nghiên cứu và tích hợp các giải pháp **Trí tuệ nhân tạo** (OpenAI API, Prompt Engineering, RAG, LangChain) vào ứng dụng thực tế để nâng cao trải nghiệm và tự động hóa quy trình nghiệp vụ.
- 📈 **Digital & Technical SEO:** Thành thạo **SEO toàn diện (On-page/Technical SEO)**, tối ưu hóa cấu trúc website, phân tích search intent và nâng cao hiệu năng trải nghiệm trang web.
- 🔭 **Định hướng hiện tại:** Mở rộng nghiên cứu về hệ thống phân tán, tự động hóa hạ tầng (DevOps) và kiến trúc tích hợp AI vào các sản phẩm quy mô lớn.
- 🤝 Mình luôn sẵn sàng hợp tác trong các dự án công nghệ, giải pháp phần mềm và ứng dụng AI.
- ⚡ **Fun fact:**
    - ☕ Đam mê code xuyên màn đêm, viết pipeline CI/CD và mày mò tích hợp các mô hình AI mới.
    - 🚀 Thích mày mò giải quyết các bài toán kiến trúc phần mềm phức tạp và đưa sản phẩm lên production mượt mà.
